# Scirocco 0.2.0 documentation archive

This version of the site was created before a complete documentation snapshot
was recorded. It does not provide a verified guide to the 0.2.0 API or build.

Use the [current documentation](/docs/intro) for the development version,
including installation, Python tutorials, and the C++ API. Current instructions
may depend on changes made after 0.2.0; use the source and build instructions
shipped with your checkout when working with an older version.
